ANIMATED GITHUB PROFILE — FABIÁN SOLA DURÁN

1. Copy README.md and the entire assets/ folder to the root of your public GitHub repository fsoladur/fsoladur.
2. Commit and push them together. Relative image paths work on GitHub when the files are in the same repository.
3. Open github.com/fsoladur to see your animated profile.
4. Open preview.html locally to preview the layout in your browser (the preview uses additional CSS and does not reproduce GitHub styling exactly).

GitHub only renders a restricted subset of HTML in README.md. The actual animations are in local SVG files (SMIL); there is no JavaScript or inline page CSS.

Tech stack in the README separates your professional backend work from AI tooling and project-based experience.

All three SVGs are editable text files. Colors can be adjusted by replacing hex codes. A few images (badges) use shields.io; the actual animations are local.
